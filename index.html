Universal Page AI

An AI helper for any web page, using your own xKiro key. On a school Chromebook, set it up as an Apps Script web app in your Google account: one file to paste, about two minutes. No key is included; you add yours in the app's Settings.

Set it up (about 2 minutes)

  1. Go to script.google.com, signed in with the account you'll use it on, and click New project.
  2. Click the title Untitled project and rename it Universal Page AI.
  3. In Code.gs, select everything (Ctrl+A), delete it, and paste the copied code (Ctrl+V). Press Ctrl+S to save.
  4. Click Deploy → New deployment. Click the gear next to "Select type" and choose Web app.
  5. Set Execute as: Me and Who has access: Only myself, then click Deploy.
  6. Click Authorize access, pick your account and click Allow. It asks to connect to external services (needed to reach xKiro and read links). If you see "Google hasn't verified this app", click Advanced → Go to Universal Page AI. That's normal for your own scripts.
  7. Copy the Web app URL (it ends in /exec) and open it. Go to Settings, paste your xKiro key and press Test connection.

If step 5 or 6 shows an error about your organization or domain, your school has blocked Apps Script web apps, and this version won't run on that account.

Want it in its own window like an app? With the web app open in Chrome: ⋮ → Cast, save and share → Create shortcut…, tick Open as window, then Create.

Updating later: paste the new code, then Deploy → Manage deployments → ✏ Edit → Version: New version → Deploy. The link stays the same.
